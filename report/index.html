Completed This Cycle

  • Implemented page-level title, description, canonical, Open Graph, and Twitter metadata across all crawlable HTML pages in this rebuild.
  • Expanded JSON-LD deployment sitewide with Organization/NGO, WebSite, WebPage, BreadcrumbList, and CollectionPage patterns on relevant templates.
  • Added content-type schema where applicable, including Service on assistance pages, BlogPosting on article/news pages, and VideoObject on video entries.
  • Strengthened overall page hierarchy with clearer section headings and more scannable structure.
  • Expanded archive and program pathways with cleaner internal links and improved discoverability.
  • Preserved important PDF resources while improving surrounding crawlable context.
  • Maintained stable directory-based URLs and global navigation consistency across rebuilt pages.

Recommended Next Actions (Remaining Work)

  • Deepen schema coverage where still partial: Person on more profile pages, FAQPage on application-focused pages, and NewsArticle/Article where newsroom formatting supports it.
  • Add AI-friendly answer blocks (What this provides, Who it helps, How to apply, Ways to support) on all major program pages for stronger generative search extraction.
  • Complete descriptive alt text QA and explicit image width/height attributes for remaining meaningful media assets.
  • Audit and merge overlapping content patterns where helpful (for example, /video-links/ and /video-library/ user journeys).
  • Add additional internal cross-links between donation, apply, and specific assistance pages to strengthen conversion pathways.
  • Continue improving PDF archive pages with short HTML summaries for each high-value document.
  • Run recurring schema validation and indexing checks, then prioritize fixes by impressions and click-through impact in search tools.

Interface Safety Controls

All SEO and AI schema improvements should be implemented without changing working layouts, donation pathways, modal behavior, video players, audio players, forms, or responsive navigation.

  • Do not alter global CSS unless needed for metadata-free visible content.
  • Do not change donation payment links.
  • Do not break header or footer navigation.
  • Do not change modal behavior.
  • Do not alter forms.
  • Do not change PDF file paths unless broken.
  • Test mobile layout after every visible change.
  • Validate schema before publishing.
